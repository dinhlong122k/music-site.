Nhập YouTube API key

Site này cần một API key của riêng bạn để tìm bài và tải playlist. Key chỉ được lưu trên máy bạn và chỉ gửi tới Google.

  1. Vào Google Cloud Console, tạo project và bật "YouTube Data API v3".
  2. Tạo một API key.
  3. Giới hạn API: chỉ chọn "YouTube Data API v3".
  4. Giới hạn ứng dụng: chọn "HTTP referrer" và thêm https://TEN-BAN.github.io/* (thêm http://localhost:*/* nếu chạy thử ở máy).
